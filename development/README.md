# Судалгаа Хөгжүүлэлтийн Ажил

`C:\Users\Owner\platform\development` нь судалгаа хөгжүүлэлтийн ажлын тусдаа module/app-ийн эхний хувилбар.

## Зорилго

Зураг дээрх Excel маягтын бүтэцтэй адил дараах ажлуудыг нэг самбарт бүртгэж, хянах:

- Танилцах, дүн шинжилгээ, судалгаа, хөгжүүлэлт
- Бүтээмжийг дээшлүүлэх, эрсдэлийг бууруулах
- Цахим шилжилт, сургалт, зөвлөгөө
- Санал, асуулга
- Тунгаалт, дүгнэлт
- Оролцоо

Хоёр дахь зураг дээрх платформын холбоосоор энэ module нь:

- `inspection-center`-ийн Хяналт шалгалтын өгөгдөл
- `bgs-policy-compliance`-ийн Журмын биелэлтийн өгөгдөл
- R&D-ийн Ажилтны дуу хоолой, эрсдэлийн удирдлага, тайлан шинжилгээний үр дүн

гэсэн урсгалыг нэгтгэх зориулалттай.

## Эхлүүлэх

```bash
npm install
npm run dev
```

Дараа нь `http://localhost:3000` нээнэ.

## Дараагийн хөгжүүлэлт

- JSON store эсвэл shared database холбох
- Санал асуулгын CRUD нэмэх
- Судалгааны тайлангийн attachment/evidence нэмэх
- Inspection Center, Policy Compliance-аас metric татах integration contract нэмэх
- Excel-ийн CXX хуудасны талбаруудыг importer-оор уншдаг болгох
